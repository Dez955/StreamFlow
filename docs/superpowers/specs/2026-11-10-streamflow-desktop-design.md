# StreamFlow (робоча назва): десктопний завантажувач відео

Дата: 2026-11-10. Статус: чернетка на огляд.

## 1. Мета

Кросплатформений десктопний застосунок із повним функціоналом терміналу yoinks (https://github.com/pablostanley/yoinks). Користувач вставляє посилання з будь-якого сайту, застосунок аналізує джерело, показує якості, і користувач завантажує файл у стандартну папку Downloads. Перша версія для MacBook M1, архітектура одразу кросплатформена (Windows 7 32-біт і новіше, Linux).

Ядро yoinks це обгортка над **yt-dlp** (1800+ сайтів) і **ffmpeg** (злиття відео й аудіо, витягання mp3). Десктопна версія використовує те саме ядро.

## 2. Що вимагав користувач (підтверджено)

- Увесь функціонал терміналу переходить у десктоп.
- Спочатку додається джерело (посилання), застосунок його аналізує, потім завантаження.
- Папка збереження за замовчуванням: Downloads на поточній ОС.
- Відсутні інструменти (yt-dlp, ffmpeg) ставляться автоматично, а якщо не вдалося, програма пише, що встановити.
- Випадаючі списки якості відео й аудіо. За замовчуванням найвища доступна. Кнопка «Завантажити» одразу дає один файл із відео та аудіо.
- Поле введення нейтральне: «Вставте посилання», без прив'язки до YouTube.
- Інтерфейс як на скріншоті: темне скло, картки черги з прогресом і кнопками Pause/Stop/Open, внизу статистика та Settings.
- Платформи: macOS (Apple Silicon M1+), Windows від 7 32-біт до 10+ 64-біт (в ідеалі), Linux.

## 3. Технологія

**Tauri 2**: ядро на Rust, інтерфейс на TypeScript + Svelte (Vite). Установник близько 10 МБ. yt-dlp і ffmpeg запускаються як окремі процеси.

Відхилені: Electron (100+ МБ), Go+Wails (менш зрілий), Python+Tkinter (застарілий вигляд, не відповідає скріншоту).

## 4. Архітектура

Три шари: UI → оболонка Tauri → `core` (чистий Rust без залежності від Tauri) → процеси yt-dlp / ffmpeg.

`core` винесено в окремий crate, щоб Legacy-оболонка (розділ 9) використовувала ту саму логіку.

### Модулі core

| Модуль | Відповідальність |
|---|---|
| `tools` | Знаходить yt-dlp та ffmpeg, при потребі докачує, оновлює yt-dlp, повертає статус і підказки. |
| `probe` | Запускає `yt-dlp -J --no-playlist <url>`, перетворює JSON на модель: заголовок, мініатюра, тривалість, списки відео- й аудіоформатів. |
| `download` | Запускає yt-dlp для одного завдання, розбирає прогрес, вмикає злиття через ffmpeg, підтримує режим «лише аудіо». |
| `queue` | Черга завдань, обмеження паралельності, статуси, пауза/відновлення/зупинка. |
| `settings` | Папка збереження, мова, паралельність, cookies з браузера, формат контейнера. |

### Команди UI → Rust

`analyze(url)`, `start(job)`, `pause(id)`, `resume(id)`, `stop(id)`, `open(id)`, `get_settings()`, `set_settings()`, `tools_status()`, `tools_install()`, `tools_update()`.

### Події Rust → UI

`tools-progress`, `download-progress` (відсоток, завантажено/усього, швидкість, ETA), `download-state` (Очікує, Завантажується, Пауза, Готово, Помилка).

## 5. Потік роботи

1. **Вставлення.** Поле з підказкою «Вставте посилання (наприклад, https://...)». Enter або кнопка пошуку запускає аналіз. При фокусі застосунок може запропонувати посилання з буфера обміну.
2. **Аналіз.** Спінер, потім картка: мініатюра, заголовок, тривалість, джерело. Якщо посилання веде на плейлист, вантажиться лише одне відео, застосунок про це повідомляє (плейлисти у розділі 11).
3. **Вибір якості.**
   - Список **Відео**: за замовчуванням «Найкраща (напр. 2160p, ~1.6 ГБ)», далі роздільності з приблизними розмірами, остання опція «Без відео (лише аудіо)».
   - Список **Аудіо**: за замовчуванням «Найкраща (напр. Opus 160k)», далі доступні бітрейти й кодеки.
   - Режим «лише аудіо» додає вибір формату: mp3 (за замовчуванням, як в yoinks), m4a, opus.
4. **Завантаження.** Кнопка «Завантажити» ставить завдання в чергу. За замовчуванням `bv*+ba/b` (найкраще відео + найкраще аудіо, злиті в один файл). Для вибраних форматів `-f <відео>+<аудіо>`. Файли пишуться у Downloads, шаблон назви `%(title)s.%(ext)s`.
5. **Готово.** Статус «Готово!», кнопка Open показує файл у Finder / Провіднику / файловому менеджері, системне сповіщення.

### Відповідність функціям yoinks

| yoinks (термінал) | Десктоп |
|---|---|
| Вставити url, вибір формату | Поле + випадаючі списки |
| Розміри форматів | Приблизний розмір у списках |
| Лише аудіо mp3 | Режим «лише аудіо» |
| Збереження у ~/Downloads, друк шляху | Downloads + Open, у картці видно шлях |
| Автоматичне завантаження yt-dlp | `tools`, кнопка «Оновити» |
| ffmpeg із PATH, інакше вбудований | `tools`, див. розділ 6 |
| Тема auto/light/dark | Як у ОС + перемикач у Settings |
| Мишка, клавіатура | Повне керування мишкою, Enter, Esc |

## 6. Інструменти (yt-dlp, ffmpeg)

- Порядок пошуку: системна копія з PATH → власна копія у папці даних застосунку (`~/Library/Application Support/<app>/bin`, `%APPDATA%\<app>\bin`, `~/.local/share/<app>/bin`).
- Якщо інструмента немає, застосунок завантажує потрібну збірку під ОС і архітектуру (macOS arm64; Windows x86 і x64; Linux x64/arm64) і перевіряє SHA-256 із офіційного релізу.
- yt-dlp можна оновити кнопкою й автоматично при помилках екстрактора («можливо, потрібне оновлення»).
- Якщо автоустановка неможлива (немає мережі, заблоковано), застосунок показує точну команду: `brew install yt-dlp ffmpeg` (macOS), `winget install yt-dlp ffmpeg` (Windows), `apt install yt-dlp ffmpeg` (Linux).
- Файли, які застосунок сам завантажив, не мають позначки карантину macOS. Складений локально застосунок без підпису запускається правою кнопкою → Open.

## 7. Помилки та межі

| Ситуація | Поведінка |
|---|---|
| Немає мережі | Зрозуміле повідомлення, кнопка «Спробувати ще». |
| Посилання не підтримується | «Цей сайт або посилання не підтримуються.» |
| Потрібен вхід / вікові обмеження | Підказка про Settings → «Взяти cookies із браузера» (Safari/Chrome/Firefox). |
| Контент із DRM (Netflix тощо) | Чітке повідомлення, що такий захист не обходиться. |
| Застарілий yt-dlp | Пропозиція оновити, повторити спробу. |
| Мало місця на диску | Повідомлення з розміром, який потрібен. |
| Зупинка | Процес завершується, `.part` залишається для докачування. |

Пауза реалізована як зупинка процесу з наступним докачуванням (`--continue`). Миттєве заморожування процесу на всіх ОС однакове не працює.

## 9. Legacy-збірка для Windows 7/8 (етап 3)

Ризикова частина, відокремлена від основної.

- Окремий корпус над тим самим `core` і тим самим UI. Інтерфейс пишеться без новітніх веб-функцій, щоб працювати на старому WebView2 (Chromium 109).
- У пакет вбудовується фіксована версія WebView2 109, остання, що працює на Windows 7/8.
- Rust-компілятор і залежності для цілі Win7 32-біт закріплюються на сумісних версіях (деталі в плані).
- yt-dlp заморожений на останній версії, що підтримує Windows 7 (на момент перевірки 2024.10.22). Станом на реліз 2026.10.26 офіційні Windows-збірки вимагають **Windows 10+**, а мінімальний Python піднято до 3.11, тож і Windows 8, і варіант «Python 3.8» для старих систем недоступні. Частина сайтів із часом перестане працювати. Застосунок повідомляє про це користувачу.
- ffmpeg: потрібна 32-бітна статична збірка, сумісна з Win7.
- **Спершу перевірка здійсненності** на вашому справжньому ноутбуці з Windows 7: чи запускається вікно, чи працює yt-dlp, чи зливає ffmpeg. Лише після успіху робиться повна збірка. Я з Mac не можу цього перевірити, потрібна ваша допомога.

Якщо перевірка не вдасться, Windows 7 виключається, інші цілі лишаються без змін.

## 10. Тестування

- **Юніт-тести `core`:** розбір JSON від yt-dlp на фікстурах (вибір «найкращого» відео й аудіо, формування списків із розмірами), розбір рядків прогресу, формування аргументів для yt-dlp, визначення шляху Downloads по ОС.
- **Інтеграційні:** завантаження короткого публічного відео з вільною ліцензією (вимикається без мережі), перевірка, що файл має і відео, і аудіо.
- **Ручна перевірка на M1:** повний сценарій зі скріншота, пауза/відновлення, режим «лише аудіо», відсутній ffmpeg.
- **CI:** GitHub Actions із матрицею macOS arm64 / Windows x64 / Windows x86 / Linux: збірка та юніт-тести.

## 11. Поза межами першої версії

Плейлисти та треди з кількома відео, субтитри, планування завантажень, вбудований програвач, обрізання відео, автовстановлення додатків-обгорток (curl-установник).

## 12. Відкриті питання для плану

1. **Контейнер за замовчуванням:** mp4 (краща сумісність із QuickTime, але VP9/AV1 не завжди відтворюються) чи mkv (завжди найвища якість). Пропоную mp4 за замовчуванням і перемикач у Settings.
2. **Назва та іконка** застосунку. StreamFlow лише робоча назва зі скріншота.
3. **Мови інтерфейсу:** пропоную українську й англійську, автовибір за мовою ОС.
4. **Перевірити:** чи випускає yt-dlp актуальну 32-бітну збірку для Windows, звідки брати 32-бітний ffmpeg, а також джерело arm64-збірки ffmpeg для macOS.
