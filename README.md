# StreamFlow

Десктопний завантажувач відео на **Tauri 2**. Вставляєте посилання з будь-якого сайту, що підтримує yt-dlp (1800+), застосунок аналізує джерело, ви обираєте якість відео й аудіо (за замовчуванням найвища) і завантажуєте один файл у папку Downloads.

Це десктопна версія [yoinks](https://github.com/pablostanley/yoinks): та сама основа (yt-dlp + ffmpeg), але з вікном замість терміналу.

## Можливості

- Поле «Вставте посилання» без прив'язки до одного сайту.
- Випадаючі списки **Відео** та **Аудіо**, за замовчуванням «Найкраща»; режим «лише аудіо» (mp3 / m4a / opus).
- Кнопка «Завантажити» без налаштувань дає один файл із відео та аудіо разом.
- Черга з прогресом, паузою, зупинкою й відкриттям файлу у файловому менеджері.
- yt-dlp та ffmpeg знаходяться в системі або докачуються автоматично (з перевіркою SHA-256); якщо не вийшло, програма показує команду для ручного встановлення.
- Налаштування: папка збереження, контейнер mp4/mkv, паралельні завантаження, cookies із браузера, мова (uk/en), тема.

## Платформи

| Платформа | Статус |
|---|---|
| macOS Apple Silicon (M1+) | перевірено: тести + збірка `.dmg` |
| Windows 10+ (32/64-біт), Linux x64 | збираються через GitHub Actions (`.github/workflows`), локально не перевірялися |
| Windows 7/8 | не підтримується в цій версії: офіційний yt-dlp вимагає Windows 10+ (див. `docs/superpowers/specs`) |

## Розробка

Потрібні Rust (rustup), Node 20+ і Xcode Command Line Tools (macOS).

```bash
npm install && npm --prefix ui install   # залежності
npm run dev                              # застосунок у режимі розробки
npm test                                 # тести UI (vitest) і Rust (cargo)
npm run build                            # збірка .app/.dmg для поточної платформи
```

Перевірка з реальною мережею (справжні yt-dlp та ffmpeg):

```bash
cargo test -p streamflow-core --test integration_real -- --ignored --nocapture --test-threads=1
```

Інтерфейс можна подивитись у браузері без Tauri: `npm --prefix ui run dev`, далі відкрити `http://localhost:5173/mock.html` (фейкові дані).

## Структура

- `core/`: Rust-ядро без залежності від Tauri (probe, args, progress, tools, runner, queue, settings).
- `src-tauri/`: тонка оболонка з командами та подіями.
- `ui/`: TypeScript + Svelte.
- `docs/superpowers/`: специфікація та план реалізації.

## Застереження

Застосунок для особистого архівування. Завантажуйте лише те, що маєте право зберігати, і дотримуйтеся умов сервісів. Контент із DRM не підтримується.
